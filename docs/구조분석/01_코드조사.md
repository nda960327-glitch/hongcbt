### 4-2. 표끼리의 관계 (컬럼 이름 기반 추정 ❓)

- `counselor_id` → counselors: bookings, inbox, reviews, chat_msgs, sessions, calls, homework, session_notes, applications 등 14개 표
- `client_id` → clients(기기 번호): bookings, orders, calls, homework, patient_links 등 10여 개 표
- `booking_id` → bookings: inbox, reviews, calls, homework
- `hospital_id` → hospitals: counselors(소속), patient_links, session_notes, posts, bookings·calls(정산 채널)
- `user_id` → users: user_sessions, oauth_handoff, user_data ❓
- users(소셜 계정)와 clients(기기 번호)를 잇는 컬럼은 스키마에 없음 — 서버 코드가 로그인 세션과 기기 번호를 따로 다룸

### 4-3. 민감 정보가 담기는 표

- 상담 내용·정신건강: inbox.body, chat_msgs.body, session_notes, homework, reviews.body, patient_weekly, user_data.v(암호화됨)
- 금융·신원: applications·counselors(자격증·연락처·계좌), hospitals(사업자번호·계좌), orders(결제), users(이메일)
- 흔적만 남기는 설계: contact_attempts(횟수만), mail_log·payout_changes(가림), rtc_signals(곧 삭제)
- 설계 원칙(schema.sql 7~10행 주석): 이용자는 계정 없이 기기 번호만 쓰는 게 기본이고, **우렁이(AI)와 나눈 대화 원문은 서버 표 어디에도 저장하지 않습니다.** 대화 원문은 기기(localStorage `cbt_messages`)에만 남습니다(js/storage.js 116~157행). 단, 답을 만들기 위해 대화가 서버를 **거쳐 OpenAI로 전송**은 됩니다 — 앱 안내 문구("외부로 전송되지 않습니다", index.html 82행)와 어긋나는 부분입니다.

## 6. 저절로 도는 작업

- **밤 청소 (매일 한국시간 새벽 3시)**: 전화 연결 신호 30분 지난 것, 점검 기록 7일, 사용량 기록 30일 지난 것 삭제. 끊긴 채 방치된 전화를 마감. 상담사 "바쁨" 표시 초기화. (wrangler.toml crons, cbtproxy.worker.js 116~131행)
- **웹훅(바깥에서 걸려오는 자동 연락)은 없습니다.** 토스·구글에서 서버로 직접 알려주는 주소가 없고, 소셜 로그인의 돌아오는 주소(/oauth/*/callback)만 있습니다.
- 요청이 올 때 겸사겸사 처리: 만료된 로그인 토큰 청소, 긴급 회기 기록의 즉시 메일 발송(ctx.waitUntil), 병원 목록 수집 이어받기 등.

## 7. 관리자용 기능

**운영자 콘솔(ops/)** — ADMIN_CODE 하나로 로그인 (ops/js/app.js 33~56행):
대시보드 통계 / 통화 관제(강제 종료) / 상담사 입점 심사(승인·반려) / 상담사 관리(정지·삭제·코드 재발급) / 이용자 현황 / 정산(지급 확인 도장) / 결제 내역(환불은 토스 관리자에서 하라고 안내) / 리뷰 관리 / AI 사용량·차단 / 연락처 감사 / 점검 로그 / 전체 공지 / 원천징수 월별 합계(홈택스 신고용) / 추천 콘텐츠 등록 / 전국 정신과 수집·제휴 / 상담소 등록·심사

**이용자 앱 속 옛 운영자 화면(js/admin.js)**: ops/가 생기기 전 쓰던 축소판이 남아 있고 지금도 함께 배포됩니다 (js/admin.js 1~6행 주석).

## 8. 배포 설정

- 서버: `wrangler.toml` → Cloudflare Workers `cbt-proxy`. D1 `hongcbt`, 실시간용 Durable Object `ChatHub`, 밤 청소 cron, 요청 제한(ratelimits) 5개.
- 앱: Cloudflare Pages 정적 배포 — neurumind(이용자), neurumind-pro, neurumind-doc, mindinside-home ❓(CORS 목록으로 추정). `_headers` 파일로 캐시 규칙.
- 안드로이드: `android/` 한 프로젝트에 이용자(com.uroong.cbt)와 상담사(com.uroong.pro) 두 가지 맛(flavor). 이용자 앱은 원격 사이트를 띄우는 방식(capacitor.config.json의 server.url). `android-pro/`는 옛 방식 ❓.
- 판 올리기: `bump.js` — sw.js 캐시 번호·index.html·version.json을 같은 번호로 올리고 `www/`로 복사. 현재 빌드 240.
- 로컬 미리보기: `.claude/launch.json` — 이용자 8317, 상담사 8319, 운영자 8323 포트.
