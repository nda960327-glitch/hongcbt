# 구조도 갱신 — 마인드 인사이드 전체 구조 문서·마인드맵 다시 만들기

코드가 많이 바뀌었을 때 docs/구조분석/ 아래 문서와 그림을 다시 만드는 명령입니다.

## 순서대로 하세요

1. **최신 코드 확보**: 이 PC의 OneDrive 폴더는 옛 파일이 섞여 있을 수 있습니다.
   `git fetch` 후 HEAD 기준으로 조사하고, git이 깨져 있으면(OneDrive 클라우드 전용 문제)
   `git clone --depth 1 https://github.com/nda960327-glitch/hongcbt.git <임시폴더>` 로 받아 그 복제본을 기준으로 삼으세요.
   기준 커밋 해시와 version.json의 빌드 번호를 문서 머리에 적으세요.

2. **코드 조사** (병렬 조사 에이전트 권장, 영역: ①서버 루트 모듈들+cbtproxy.worker.js ②schema*.sql ③이용자 앱 js/ 코어 ④이용자 앱 js/ 기능들 ⑤pro/·doc/·ops/·home/·배포):
   - 규칙: 추측 금지, 코드에 있는 것만. 불확실은 ❓. 모든 항목에 파일 경로 근거.
   - 비밀값은 이름만 적고 값은 절대 옮기지 않기. 하드코딩 발견 시 위치만.
   - 결과를 `docs/구조분석/01_코드조사.md` (폴더 구조·화면·API·DB·외부 서비스·자동 작업·관리자·배포)에 정리.

3. **기능 목록**: `docs/구조분석/02_기능목록.md` — 번호/이름(쉬운 말)/한 줄 설명/화면/파일/다음 기능/외부 서비스/상태(✅🚧💤).

4. **확인 필요**: `docs/구조분석/03_확인필요.md` — ❓ 목록, 안 쓰는·미완성 코드, 위험 위치(내용 말고 위치만).

5. **마인드맵**: `docs/구조분석/mindmap/*.mmd` 수정 또는 재작성.
   - 문법: mermaid `flowchart` 사용. 둥근 상자=화면/앱, 네모=기능, 원기둥=저장소, 점선 육각형 `{{ }}`+`classDef ext stroke-dasharray: 5 4`=외부 서비스. 흐름도는 ①② 번호.
   - 상자 안 둘째 줄에 `<small>파일 경로</small>`.
   - 한 장에 상자 25개 이하. 긴 흐름도는 2단 구성:
     바깥 `flowchart LR` + `subgraph COL1/COL2 [" "]`(안쪽 `direction TB`) + 열끼리 `COL1 == "…" ==> COL2` 연결 + `style COL1 fill:none,stroke:none`.
     (주의: 열 안 상자를 다른 열 상자와 직접 이으면 안쪽 방향이 무시됨)
   - **파일은 UTF-8(BOM 없음)·LF로 저장** — PowerShell `Set-Content`로 쓰면 BOM/CRLF 때문에 mermaid 머리말 파싱이 깨집니다.

6. **변환**:
   ```bash
   npx -y @mermaid-js/mermaid-cli -i <파일>.mmd -o <파일>.svg -b white
   npx -y @mermaid-js/mermaid-cli -i <파일>.mmd -o <파일>.png --size 2200 -b white
   ```
   (버전에 따라 `-w` 대신 `--size`)

7. **PDF**: `docs/구조분석/_인쇄용.html`(표지+각 SVG를 A3 가로 한 쪽씩)을 수정한 뒤 Edge 헤드리스로 인쇄:
   ```bash
   msedge --headless --disable-gpu --no-first-run --user-data-dir=<임시폴더> --print-to-pdf=<임시폴더>/out.pdf --no-pdf-header-footer file:///<경로>/print.html
   ```
   - 한글 경로에 바로 출력하면 실패할 수 있으니 임시 영문 경로에 만들고 복사.
   - `--user-data-dir`을 따로 주지 않으면 프로필 잠금으로 실패할 수 있음.
   - 결과를 `docs/구조분석/마인드인사이드_구조_YYYYMMDD.pdf`로 저장(오늘 날짜).

8. **자체 점검**: PNG와 PDF를 직접 열어 볼 것 — 한글 잘림/겹침, 상자마다 경로 있는지, 어려운 말 없는지, 비밀값 없는지, 25상자 이하인지.
