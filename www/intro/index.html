1환자 입장 neurumind.com

정신과에서 "이 앱 써보세요"라고 권해서 깔았거나, 스스로 찾아 깔았거나 — 둘 다 같은 앱입니다.

첫 하루

  1. 설치하고 로그인카카오·네이버·구글 중 하나로 시작합니다. 회원가입 폼이 없습니다. 안드로이드 앱과 웹앱은 같은 화면입니다.
  2. 느루를 만난다온보딩에서 이름과 요즘 마음 상태를 물어봅니다. 느루는 달팽이 의사 캐릭터로, "뇨롱!", "후룽, 느루느루.", "쭈굴…", "호고고곡?!" 같은 의성어를 씁니다. 귀엽고 조금 하찮은 게 의도입니다.
  3. 홈에서 오늘 할 일을 본다기분 체크인 → 누르면 7일 기분 그래프로 바뀝니다. 그 아래 '오늘 할 일'에 미션 하나, 상담사 숙제, 케어플랜 항목이 날짜와 함께 뜹니다. 하루 경계는 새벽 5시라 밤늦게 해도 오늘로 칩니다.
  4. 느루와 이야기한다인지행동치료(CBT) 기반의 AI 대화. 생각 기록·감정 라벨링·행동 활성화를 대화 속에서 자연스럽게 유도합니다. 위기 표현이 나오면 위기상담 번호(1577-0199)를 바로 안내합니다.

계속 쓰게 만드는 것들

느루의 추천

운영자가 올린 정신건강 영상·글. 👍 도움됐어요 / 👎 별로예요 로 투표하면 순서가 바뀝니다. '전체 보기'에서 태그별로 훑어봅니다.

내 마음 도구

생각 기록, 밤 일기, 호흡·안정 도구, 자가 검사(PHQ-9·GAD-7), 배움 카드, 목표.

성장 요소

미션 완료 → 느루 캐시·경험치. 연속 사용(스트릭)과 보호막, 농장·옷장 같은 가벼운 보상.

느루의 주간 편지

매주 월요일 새벽 5시, 한 주의 기분·기록을 모아 느루가 편지를 씁니다. 카드로 저장·공유할 수 있습니다.

대면상담 및 진료 — 내 주변 정신과

홈 맨 아래. 위치를 허용하면 가까운 정신건강의학과가 거리순으로 뜹니다(네이버 지도 데이터, 전국). 전화·길찾기 한 번에. 운영팀이 등록한 제휴 병원은 배지가 붙고, 앱 연동 병원은 진료 뒤 병원 코드로 담당의와 바로 이어집니다. 위치 권한이 없으면 동네·역 이름으로 찾습니다.

사람 상담이 필요할 때

  1. 상담사 마켓에서 고른다대시보드 → 상담. 상담사 프로필·리뷰·요금을 보고 예약하거나, 지금 가능한 상담사에게 '바로상담'(채팅·음성 통화)을 겁니다.
  2. 느루 캐시로 결제상담료는 느루 캐시로 냅니다. 캐시 1 = 1원. 상담사 97%, 결제 수수료 3%, 플랫폼은 상담료에서 가져가지 않습니다. 구독('마인드 인사이드 구독')은 느루 대화 무제한 등 앱 기능에 대한 것이고, 상담료와는 별개입니다.
  3. 숙제를 받는다상담사가 낸 숙제가 채팅 말풍선과 '오늘 할 일'에 함께 뜹니다. 언제 받았고 언제 했는지 날짜가 붙습니다.
  4. 상담 후 확인상담사가 완료 처리하면 환자가 '잘 받았어요'로 확인하거나, 3일 뒤 자동 확정됩니다. 이의가 있으면 정산을 멈출 수 있습니다.

정신과에서 권해서 깔았다면 — 담당 병원 연결

마이 → 담당 병원
🏥 담당 병원 연결하기병원 코드 H-XXXX-XXXX
📝 병원과 나누는 기록상담 요약 · 담당의 피드백
📊 주간 상태 요약 공유켜짐
  1. 진료실에서 받은 코드를 넣는다코드 + 이름(+생년) 을 넣고 '동의하고 연결하기'. 이때 주간 상태 요약 공유에도 동의할지 고릅니다 (기본 켜짐, 언제든 끌 수 있음).
  2. 이후 자동으로 이어진다상담사가 남긴 회기 기록이 담당의에게 보이고, 담당의 피드백이 알림함과 '병원과 나누는 기록'에 도착합니다. 주 1회 기분 평균·체크인 횟수·미션 수 같은 숫자만 병원에 올라갑니다.
  3. 절대 안 가는 것느루와 나눈 대화, 일기 원문, 생각 기록 내용. 이건 기기 안에만 있습니다. 느루도 "그 대화는 병원에 안 가요"라고 안심시켜 줍니다.

2상담사 입장 pro.neurumind.com

심리상담사가 입점해서 예약을 받고 상담하고 정산받는 곳. 진료 사이 3분에 답장하는 사람을 위해 설계했습니다.

  1. 입점 신청 → 승인자격·소속을 적어 신청하면 접수 메일이 가고, 운영자가 승인하면 열람 코드가 메일로 옵니다. 코드는 한 번 넣으면 그 기기에서 계속 열립니다. 이메일 매직링크로도 들어올 수 있습니다 (15분·1회용).
  2. 홈에서 하루를 본다오늘 예약, 안 읽은 채팅, 걸려온 전화, 받은 상담 자료, 내가 낸 숙제, 담당의 피드백, 그리고 회기 기록 칸.
  3. 상담한다예약 상담 · 채팅 · 음성 통화(전화번호는 서로 안 보임). 채팅에서 연락처를 주고받으면 서버가 가립니다 — 플랫폼 밖으로 나가면 안전장치도 정산도 사라지기 때문.
  4. 숙제를 낸다대화방의 '숙제' 버튼. 환자 앱의 '오늘 할 일'에 바로 뜹니다.
  5. 상담이 끝나면 회기 기록을 남긴다 — 필수요약(필수) · 다음 계획 · 위험도(없음/주의/긴급) · 낸 숙제 · 담당 병원 공유 여부. 예약을 '완료'로 표시하면 기록 시트가 바로 열립니다.
  6. 정산상담사 97%. 내담자 확인(또는 3일 자동 확정) 뒤 운영자가 지급합니다. 회기 기록이 없는 상담은 정산에 올라가지 않습니다. 정산 탭에 '기록 없어 보류 N건'이 뜹니다.

왜 강제하나요? 기록이 없으면 담당의는 환자가 상담을 받았다는 사실조차 모릅니다. 병원이 이 앱을 권하려면 "상담하면 반드시 기록이 남는다"가 보장돼야 합니다. 그래서 정산 조건으로 걸었습니다.

'긴급'을 찍으면 담당 병원에 등록된 의사 이메일로 즉시 메일이 갑니다 (한 기록당 한 번). 기록을 병원과 공유하지 않기로 했더라도 "누가·언제·긴급"이라는 사실만은 알립니다.

3의사 입장 doc.neurumind.com

정신과 의사가 자기 환자의 상담 경과를 보고 상담사에게 방향을 주는 곳. 진료실에서 쓰는 걸 전제로 아주 단순합니다.

  1. 병원 등록은 운영팀이운영자 콘솔 → 병원 관리에서 병원 이름·진료과·담당의·이메일을 넣으면 병원 코드 H-XXXX-XXXX가 나옵니다. 코드는 환자 연결용이자 비상 로그인용입니다.
  2. 이메일 링크로 로그인의사 앱에 이메일을 넣으면 로그인 링크가 옵니다 (15분·1회용, 이 기기 30일). 상담사와 같은 방식이라 코드가 카톡으로 돌다 새는 일이 없습니다. 이메일이 없으면 코드로도 들어올 수 있습니다.
  3. 환자에게 코드를 알려준다"앱 → 마이 → 담당 병원 연결하기에 이 코드 넣으세요." 환자가 넣으면 의사 앱 목록에 나타납니다.
  4. 환자 목록 → 타임라인긴급 표시된 환자가 맨 위. 환자를 누르면 상담사 회기 기록·낸 숙제(완료 여부)·내 피드백·예약이 시간순으로 보이고, 그 위에 주간 상태 막대그래프(기분 평균 1~5, 체크인·미션·연속일)가 있습니다.
  5. 피드백을 쓴다"상담사에게만 / 환자에게만 / 둘 다". 상담사 앱 홈과 환자 앱 알림함에 그대로 도착합니다. 특정 회기 기록에 대한 피드백으로 달 수도 있습니다.
  6. 긴급 알림을 받는다상담사가 '긴급'을 표시한 순간 이메일이 옵니다. 앱을 열면 빨간 띠로 다시 보입니다.

4관리자 입장 ops.neurumind.com

운영팀이 쓰는 콘솔. 운영자 코드 하나로 들어갑니다 (이 페이지 맨 아래 테스트 코드 참고).

대시보드

오늘 대화·활성 사용자·매출·지급 대기를 한 화면에. 최근 추이 그래프.

입점 신청 · 상담사

신청 승인/반려(메일 자동 발송), 상담사 코드 발급·재발급·정지, 계좌 확인.

정산

회기 기록까지 있는 완료 상담만 '지급 대기'에. 기록이 없는 건은 정산 보류 목록에 상담사별로 표시. 실제 이체 뒤 '지급 완료'로 표시.

결제 · 리뷰 · 내담자

느루 캐시 충전·구독 결제 내역, 리뷰 관리, 내담자 조회.

추천 콘텐츠

유튜브 링크나 글을 올리면 환자 홈 '느루의 추천'에 뜹니다. 태그·투표 현황 확인.

병원 관리

병원 등록(이름·진료과·담당의·이메일) → 코드 발급. 연결 환자 수·피드백 수·마지막 접속. 코드 재발급·정지.

사용량 · 진단

OpenAI 토큰 사용량, 메일 발송 로그, 통화 연결 진단, 서비스 상태.

운영자 코드는 전체 데이터를 여는 마스터키입니다. 새면 즉시 재설정합니다 (Worker 시크릿 ADMIN_CODE).

5개인정보 원칙 — 팀원이 외워야 할 네 줄

  1. 환자의 대화·일기 원문은 서버에 없다. AI 호출은 프록시를 거치되 저장하지 않는다. 병원에도 안 간다.
  2. 환자는 계정이 없다. 기기 ID + 서명 키로 식별한다. 병원이 알아볼 이름·생년은 환자가 연결할 때 직접 준다.
  3. 공유는 언제나 환자의 동의로 시작하고, 환자가 끌 수 있다. 병원 연결 해제, 주간 요약 끄기 모두 즉시 반영·삭제.
  4. 기록은 상담사가 쓴다. 의사가 보는 건 상담사의 요약이지 환자의 말이 아니다. 그래서 기록을 정산 조건으로 걸었다.

7팀원용 테스트 코드

비밀번호를 넣으면 지금 서버에 있는 테스트 병원·상담사·운영자 코드를 보여줍니다. 코드는 페이지에 박혀 있지 않고 서버에서 그때그때 가져옵니다.

이 코드로 한 바퀴 돌아보기

  1. 환자 앱 열기 → 카카오/네이버/구글로 로그인 → 마이 → 담당 병원 연결하기 → 병원 코드 + 아무 이름.
  2. 프로 앱 열기 → 상담사 코드 입력 → 홈 '회기 기록' 칸에서 방금 그 환자에게 기록을 남기고 위험도를 '긴급'으로 → 담당의 이메일로 알림이 갑니다.
  3. 닥터 앱 열기 → 담당의 이메일로 링크를 받거나 병원 코드로 입장 → 환자 목록에서 빨간 '긴급' 확인 → 피드백 쓰기.
  4. 운영자 콘솔 → 정산 탭에서 '정산 보류 — 회기 기록 없음' 목록, 병원 관리에서 병원 이메일 확인.
주의 운영자 코드는 전체 데이터를 여는 마스터키입니다. 팀 밖으로 보내지 마세요. 샌 것 같으면 운영팀이 ADMIN_CODE 를 재설정하면 이 페이지는 자동으로 새 코드를 보여줍니다.

테스트 병원·상담사는 실제 운영 데이터와 같은 DB 에 있습니다. 실제 환자 정보를 넣지 마세요.

8자주 묻는 질문

무료인가요?
환자 앱은 무료로 시작합니다. 느루와 하루 30회 대화, 체크인·기록·미션은 무료. 7일 체험 뒤 '마인드 인사이드 구독'을 하면 대화가 무제한이 됩니다. 사람 상담은 느루 캐시로 건별 결제.
느루 캐시는 뭔가요?
앱 안의 화폐(1캐시 = 1원). 미션으로 조금씩 받고, 상담을 받으려면 충전합니다. 상담사에게 97%가 갑니다.
병원 코드가 새면?
운영자 콘솔에서 '코드 재발급'. 이미 연결된 환자는 유지되고, 옛 코드로는 더 못 들어옵니다. 의사는 이메일 링크로 다시 들어오면 됩니다.
의사가 환자의 대화를 볼 수 있나요?
아니요. 볼 수 있는 건 상담사가 쓴 회기 기록, 낸 숙제, 그리고 환자가 동의한 주간 숫자(기분 평균 등)뿐입니다.
상담사가 기록을 안 남기면?
그 상담은 정산되지 않습니다. 상담사 앱과 운영자 콘솔 양쪽에 '기록 없어 보류'로 뜹니다.
앱 이름이 왜 두 개처럼 보이죠?
서비스 이름은 마인드 인사이드, 캐릭터 이름은 느루입니다. 예전 이름(우렁의사)은 더 쓰지 않습니다.
