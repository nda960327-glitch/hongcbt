# 앱 알림(FCM) 켜는 법 — 사장님이 하실 일

## 왜 이걸 하나요

지금까지 알림은 **웹푸시**로 보냈습니다. 브라우저에서는 잘 됩니다.
그런데 **스토어에서 받은 앱에서는 알림이 오지 않습니다.**

이유는 이렇습니다. 우리 앱은 앱 안에 웹을 넣은 게 아니라,
앱이 켜지면 `neurumind.com` 을 통째로 불러와 보여주는 방식입니다.
그 앱 안 화면에는 **서비스워커**(웹푸시를 받아주는 작은 배달원)가 등록되지 않습니다.
배달원이 없으니 웹푸시는 문 앞까지 와서 그냥 돌아갑니다. 실기기 로그로 확인했습니다.

그래서 **앱에서는 안드로이드가 원래 쓰는 알림 통로(FCM)** 로 바꿉니다.
웹 브라우저는 지금처럼 웹푸시 그대로입니다. 서버가 알아서 갈라 보냅니다.

아래 여섯 단계를 한 번만 해두시면 됩니다. 15~20분이면 끝납니다.

---

## 1단계 — Firebase 프로젝트 만들기

1. https://console.firebase.google.com 접속 (구글 계정으로 로그인)
2. **프로젝트 추가** 클릭
3. 프로젝트 이름: `uroong` (아무거나 괜찮습니다)
4. 애널리틱스는 **꺼도 됩니다** (알림에는 필요 없습니다)
5. 만들기 → 잠깐 기다리면 프로젝트가 열립니다

---

## 2단계 — 안드로이드 앱 **두 개** 등록하기

우리 앱은 두 개입니다. 둘 다 등록해야 합니다.

프로젝트 화면 가운데의 **안드로이드 아이콘**을 누르고,

**첫 번째 (내담자 앱)**
- Android 패키지 이름: `com.uroong.cbt`
- 앱 닉네임: `우렁의사`
- 서명 인증서 SHA-1: **비워두세요** (알림에는 필요 없습니다)
- 앱 등록 → 다음 → 다음 → **콘솔로 이동**

**두 번째 (상담사 앱)**
- 프로젝트 개요 옆 **톱니바퀴 → 프로젝트 설정 → 내 앱 → 앱 추가 → 안드로이드**
- Android 패키지 이름: `com.uroong.pro`
- 앱 닉네임: `우렁의사 프로`
- SHA-1 은 역시 비워두세요

> 반드시 **같은 Firebase 프로젝트 안에** 두 개를 넣으세요.
> 그래야 설정 파일 한 장으로 두 앱이 함께 돌아갑니다.

---

## 3단계 — `google-services.json` 내려받아 넣기

1. **톱니바퀴 → 프로젝트 설정 → 내 앱**
2. `com.uroong.cbt` 쪽의 **google-services.json 다운로드** 클릭
   (두 앱을 다 등록한 뒤에 받으면, 파일 하나에 두 앱이 다 들어 있습니다)
3. 받은 파일을 **정확히 이 자리**에 넣습니다:

```
C:\Users\SAMSUNG\.gemini\antigravity\scratch\hongcbt\android\app\google-services.json
```

즉 `android/app/` 폴더 안입니다. `android/` 바로 밑이 아닙니다.

**확인하는 법** — 그 파일을 메모장으로 열어 `com.uroong.cbt` 와 `com.uroong.pro`
두 글자가 모두 보이면 제대로 받으신 겁니다.
하나만 보이면 2단계에서 앱 하나를 빠뜨린 것이니 다시 받으세요.

> 이 파일이 없어도 앱 빌드는 그대로 됩니다(알림만 조용히 꺼집니다).
> 그래서 지금 당장 안 하셔도 앱이 깨지지는 않습니다.

---

## 4단계 — 서비스계정 키 받기 (서버가 알림을 보낼 자격증)

1. **톱니바퀴 → 프로젝트 설정 → 서비스 계정** 탭
2. **새 비공개 키 생성** → **키 생성**
3. `uroong-firebase-adminsdk-....json` 같은 파일이 내려옵니다
4. 메모장으로 열면 이런 내용이 있습니다:

```json
{
  "type": "service_account",
  "project_id": "uroong-1234",
  "private_key": "-----BEGIN PRIVATE KEY-----\nMIIEv...아주 긴 글자...\n-----END PRIVATE KEY-----\n",
  "client_email": "firebase-adminsdk-xxxxx@uroong-1234.iam.gserviceaccount.com",
  ...
}
```

여기서 **세 개**를 쓸 겁니다: `project_id` · `client_email` · `private_key`

> ⚠️ 이 파일은 **비밀번호와 같습니다.**
> 이걸 가진 사람은 우리 사용자 전원에게 알림을 보낼 수 있습니다.
> 저장소(깃허브)에 절대 올리지 마시고, 다 넣은 뒤에는 지우거나 안전한 곳에 보관하세요.

---

## 5단계 — 서버에 시크릿 세 개 넣기

프로젝트 폴더에서 터미널을 열고 아래를 **한 줄씩** 실행합니다.
실행하면 값을 붙여넣으라고 물어봅니다.

```
npx wrangler secret put FCM_PROJECT_ID
```
→ `project_id` 값을 붙여넣기 (예: `uroong-1234`)

```
npx wrangler secret put FCM_CLIENT_EMAIL
```
→ `client_email` 값을 붙여넣기 (예: `firebase-adminsdk-xxxxx@uroong-1234.iam.gserviceaccount.com`)

```
npx wrangler secret put FCM_PRIVATE_KEY
```
→ `private_key` 값을 붙여넣기.
   **`-----BEGIN PRIVATE KEY-----` 부터 `-----END PRIVATE KEY-----\n` 까지 통째로**,
   따옴표(`"`)는 빼고, JSON 에 적힌 `\n` 글자도 **그대로 둔 채** 붙여넣으면 됩니다.
   (서버가 `\n` 을 알아서 줄바꿈으로 되돌립니다)

> 워커 계정을 확인하세요 — `npx wrangler whoami` 가 **nda960327** 계정이어야 합니다.

넣고 나서 워커를 다시 배포합니다:
```
npx wrangler deploy
```

## 6단계 — 데이터베이스에 칸 하나 추가

앱 기기의 알림 주소를 따로 표시해 둘 칸입니다. **딱 한 번만** 실행하세요.

```
npx wrangler d1 execute hongcbt --remote --command "ALTER TABLE push_subs ADD COLUMN kind TEXT DEFAULT 'web'"
```

이미 넣었는데 또 실행하면 "중복 칸" 오류가 납니다 — 그건 그냥 무시하셔도 됩니다.

> 이 칸을 안 만들어도 서버는 죽지 않습니다.
> 다만 그때까지는 앱의 알림 등록이 저장되지 않아 앱 알림만 안 옵니다.

---

## 다 하셨으면 — 확인

1. 안드로이드 스튜디오에서 **두 앱을 새로 빌드**해서 폰에 설치
   (`google-services.json` 은 빌드할 때 앱 안으로 들어갑니다 — 기존 설치본은 그대로면 안 됩니다)
2. 앱을 켜면 **"알림을 보내도록 허용하시겠습니까?"** 가 뜹니다 → 허용
3. 앱을 **완전히 닫고**(최근 앱에서 밀어서 종료), 다른 폰이나 PC 브라우저에서 메시지·전화를 보내보세요
4. 폰 상단에 **"새 소식이 도착했어요"** 알림이 뜨면 성공입니다

### 알림 권한은 어떻게 되나요 (자동 허용 관련)

**안드로이드 13부터는 앱이 알림을 대신 켜줄 수 없습니다.** 구글이 막았습니다.
설치만 해도 알림이 켜지던 건 안드로이드 12까지의 이야기입니다.
(안드로이드 12 이하 기기에서는 지금도 **설치와 동시에 알림이 켜져 있습니다** — 아무것도 안 하셔도 됩니다.)

그래서 **최대한 자동에 가깝게** 만들어 두었습니다.

- **내담자 앱**: 앱을 켜는 **바로 그 순간** 시스템 팝업이 뜹니다. '허용' 한 번이면 끝입니다.
- **상담사 앱**: **로그인 직후 바로** 시스템 팝업이 뜹니다.
- 허용을 누르면 **기기 등록(토큰 전송)까지 자동**입니다. 따로 누를 버튼이 없습니다.
- 실수로 '거부'를 눌렀다면 — 안드로이드는 그 팝업을 다시 띄워주지 않습니다.
  그래서 앱 안에 **'설정 열기'** 버튼을 넣었습니다. 한 번 누르면 그 앱의 알림 설정 화면이 바로 열립니다.
  (내담자 앱: 설정 → 알림 받기 칸 / 상담사 앱: 홈의 빨간 카드, 설정 → 알림·소리)
- 설정에서 켜고 앱으로 돌아오면 **그 순간 자동으로 등록**됩니다. 앱을 다시 켤 필요 없습니다.

**안 되면** — 운영자 앱의 진단 화면(`/api/admin/diag`)에서 다음을 확인하세요.

| stage | msg | 뜻 |
|---|---|---|
| `fcm-plugin` | `ok` | 앱 안에서 알림 기능이 잡혔습니다 (정상) |
| `fcm-plugin` | `missing` | 앱 웹뷰가 알림 기능을 못 봤습니다 — 앱을 새로 빌드해서 설치했는지 확인 |
| `fcm-perm` | `denied` | 사용자가 알림 권한을 거부했습니다 — 폰 설정 → 앱 → 알림에서 켜기 |
| `fcm-regerr` | (아무 글자) | `google-services.json` 이 없거나 패키지 이름이 안 맞습니다 (2·3단계) |
| `fcm-token` | `len142` 같은 것 | 기기 알림 주소를 정상적으로 받았습니다 |
| `fcm-sub` | `ok` | 서버에 저장됐습니다 (정상) |
| `fcm-sub` | `schema` | 6단계(칸 추가)를 안 하셨습니다 |

## 정리 — 안 하면 어떻게 되나요

아무것도 안 하셔도 **지금과 똑같이** 돌아갑니다.
앱 빌드도 되고, 웹 알림도 그대로 나갑니다.
다만 **스토어 앱의 알림만 계속 안 옵니다.**

파일 한 장(3단계)과 시크릿 세 개(5단계), 칸 하나(6단계) —
이 셋이 다 갖춰지는 순간부터 앱 알림이 살아납니다.
